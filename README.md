# The Last Toast 🥀

A digital invitation I designed and built for my 22nd birthday: a semi-formal murder mystery dinner party.

The website brings together the event details, dress code, RSVP form, FAQ and birthday wishlist in one slightly suspicious place.

### [View the live website →](https://vivil10n.github.io/the-last-toast/)

## Built with

* HTML
* CSS
* GitHub Pages
* Google Forms for RSVPs
* Are.na for the embedded wishlist

## About the design

I wanted the invitation to feel like a candlelit dinner party with a secret—using deep reds and vintage-inspired typography to create something mysterious without feeling too serious.

Designed and built by [Vivian Truong](https://www.vivitruon.com/).
